# Module 2 — Survivre dans l'espace


## Bloc 1
type: text
title: "Introduction immersive"
content: |
  Tu es à bord de la station.

  Tout semble calme.

  Mais en réalité, chaque seconde :
  - l'air est recyclé,
  - l'oxygène est contrôlé,
  - la pression est maintenue,
  - le CO₂ est éliminé.

  Ton instructeur te dit :

  **« Tu ne respires pas l'espace. Tu respires une machine. »**

  Dans ce module, tu vas comprendre :
  - pourquoi pression et oxygène sont vitaux,
  - comment les systèmes de support vie fonctionnent,
  - pourquoi une panne devient immédiatement critique.

## Bloc 3
type: text
title: "1. Pourquoi la pression est essentielle"
content: |
  Sur Terre, nous vivons sous une pression atmosphérique constante.

  Cette pression permet :
  - au sang de circuler correctement,
  - aux gaz de rester dissous dans le corps,
  - aux échanges respiratoires de fonctionner.

  Dans l'espace :
  - la pression est quasi nulle,
  - le corps n'est pas adapté à ces conditions.

  C'est pour cela que :
  - la station est pressurisée,
  - les combinaisons EVA sont pressurisées.

  Sans pression :
  - les fonctions vitales sont rapidement compromises.

## Bloc 4
type: quiz
question: "Quel est le rôle principal de la pression dans un environnement habitable ?"
options:
  - "Permettre le fonctionnement normal du corps humain"
  - "Maintenir la température à un niveau stable"
  - "Empêcher les fluides corporels de remonter vers la tête"
  - "Faciliter la communication radio entre les membres d'équipage"
correct_answer: "Permettre le fonctionnement normal du corps humain"
explanation: |
  La pression permet les échanges gazeux et le fonctionnement physiologique normal. Les autres réponses décrivent des contraintes réelles en microgravité, mais elles ne sont pas liées au rôle de la pression atmosphérique.

## Bloc 5
type: text
title: "2. L'oxygène : indispensable mais contrôlé"
content: |
  Le corps humain dépend de l'oxygène pour produire de l'énergie.

  Dans la station :
  - l'oxygène est généré ou stocké,
  - son niveau est surveillé en permanence.

  Trop peu d'oxygène :
  - perte de conscience,
  - danger vital.

  Trop d'oxygène :
  - risque d'incendie accru.

  L'équilibre est donc critique.


---

## Bloc 7
type: text
title: "3. Le CO₂ : un danger invisible"
content: |
  Chaque respiration produit du dioxyde de carbone (CO₂).

  Dans un environnement fermé :
  - le CO₂ s'accumule,
  - il devient dangereux.

  Les systèmes de support vie doivent :
  - filtrer le CO₂,
  - maintenir un air respirable.

  Sans cela :
  - fatigue,
  - confusion,
  - perte de conscience.

## Bloc 9
type: text
title: "4. Le système de support vie (ECLSS)"
content: |
  La station utilise un système appelé :

  **ECLSS — Environmental Control and Life Support System**

  Il gère :
  - l'oxygène,
  - le CO₂,
  - la pression,
  - l'eau,
  - l'humidité.

  Ce système permet :
  - de recréer un environnement habitable,
  - de maintenir la vie sur le long terme.

  Sans lui :
  aucune mission longue n'est possible.

## Bloc 11
type: text
title: "5. L'eau : une ressource critique"
content: |
  Dans l'espace, l'eau est une ressource limitée.

  Elle est utilisée pour :
  - la boisson,
  - l'hygiène,
  - certaines réactions chimiques du système de support vie.

  Sur l'ISS, l'eau est recyclée :
  - à partir de l'humidité de l'air,
  - à partir de l'urine des astronautes.

  Ce recyclage est essentiel pour réduire les besoins en ravitaillement.

  Sans gestion de l'eau :
  - la mission est rapidement compromise.


---

## Bloc 13
type: text
title: "6. Une panne = une urgence"
content: |
  Les systèmes de support vie ne sont pas redondants par luxe.

  Chaque composant critique est doublé ou prévu avec des procédures de secours.

  Une panne peut entraîner :
  - une montée de CO₂,
  - une chute de pression,
  - une diminution de l'oxygène disponible.

  Dans chaque cas, l'équipage dispose de :
  - protocoles d'urgence,
  - équipements de secours,
  - délais d'intervention précis.

  La résilience du système est conçue au même niveau d'exigence que les opérations de vol.

## Bloc 16
type: case-study
title: "Étude de cas — Une montée silencieuse du CO₂"
case: |
  Pendant une période de travail intense, un astronaute ressent :
  - une fatigue inhabituelle,
  - des maux de tête croissants,
  - une baisse de concentration.

  Les capteurs indiquent une montée progressive du CO₂ depuis 2 heures.

questions:
  - "Pourquoi les symptômes sont-ils apparus progressivement ?"
  - "Quel est le lien entre CO₂ et performance opérationnelle ?"
  - "Pourquoi une surveillance continue des paramètres est-elle indispensable ?"

correction: |
  **Analyse attendue :**

  1. Le CO₂ s'accumule lentement dans un environnement fermé. Les effets apparaissent progressivement — ce qui les rend difficiles à identifier sans instrumentation.

  2. Un taux de CO₂ élevé affecte la cognition, la concentration et les capacités motrices. Cela peut compromettre la prise de décision dans des situations critiques.

  3. Les symptômes peuvent être confondus avec de la fatigue ou du stress. Seule une surveillance continue et automatisée permet de détecter une dérive avant qu'elle devienne dangereuse.
